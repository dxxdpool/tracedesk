## Problem

With 2 books per page, page 1 of the catalog should list Beloved, Carrie but shows Dune, Emma. The last page is empty. Tests started failing after the latest refactor.

## Root cause

**In shelf/paginate.py, page\_offset returns page \* per\_page instead of (page - 1) \* per\_page, so every page starts one page too far into the list: page 1 returns Dune/Emma and the last page runs past the end and is empty.**

Verified (`6e25ca94`) by:

- experiment `848bc67a`: `python -m pytest -q tests/test_catalog.py::test_first_page_starts_with_first_title` approved by human, exit code 1, outcome `confirms`

Supporting evidence:

- `shelf/paginate.py:11-13`: page\_offset multiplies page by per\_page, so page 1 starts at index 2, not 0. (by investigator)
- `shelf/paginate.py:16-21`: paginate uses page\_offset as start and slices items\[start:start+per\_page\], so the bad offset shifts every page. (by investigator)
- commit `5d637281e5ca` in `shelf/paginate.py`: Refactor replaced start = (page - 1) \* per\_page with page\_offset(page, per\_page), which returns page \* per\_page. (by investigator)
- `tests/test_catalog.py:16-21`: Sorted titles are beloved,carrie,dune,emma,ivanhoe. With per\_page=2, page 1 doc expects index 0-1 (Beloved,Carrie) and page 3 expects index 4 (Ivanhoe); page\*per\_page gives start 2 and 6, matching the reported Dune/Emma and empty last page. (by skeptic)

`shelf/paginate.py:16-21`

```
def paginate(items: list, page: int, per_page: int = 10) -> list:
    """Return the items on `page` (1-based)."""
    if page < 1:
        raise ValueError("page must be at least 1")
    start = page_offset(page, per_page)
    return items[start : start + per_page]
```

`shelf/catalog.py:6-13`

```
def browse(books: list[dict], page: int, per_page: int = 10) -> dict:
    """One page of the catalog, sorted by title, with paging info."""
    ordered = sorted(books, key=lambda book: book["title"].lower())
    return {
        "page": page,
        "pages": page_count(len(ordered), per_page),
        "books": paginate(ordered, page, per_page),
    }
```

`shelf/paginate.py:4-8`

```
def page_count(total: int, per_page: int) -> int:
    """How many pages are needed for `total` items."""
    if per_page < 1:
        raise ValueError("per_page must be at least 1")
    return -(-total // per_page)
```
